# 跨会话记忆规则

## 规则说明

你在每个新对话启动时会通过 SessionStart hook 自动读取 `~/.claude/session_memory.md` 中的内容。你需要在此基础上维护跨会话的记忆。

## 读取规则

- 对话开始时，session_memory.md 的内容已经通过 hook 注入到你的上下文中。
- 在回应用户之前，先回顾注入的记忆内容，确保延续之前的上下文。
- 如果记忆内容与当前对话矛盾（例如用户说"我已经放弃那个方案了"），信赖当前对话的内容，并更新记忆文件。

## 写入规则

当以下情况发生时，主动将关键信息写入 `~/.claude/session_memory.md`：

1. **用户明确表示要结束对话**（如"好的没别的了"、"先这样"、"再见"、"谢谢，我先试试"）—— 立即总结本次对话的关键结论、已完成的事项、遗留问题，并写入记忆文件。
2. **完成了一项主要任务**（如修复了一个 bug、实现了一个功能、完成了一次分析）—— 写入任务结论和关键决策。
3. **用户做出了重要的配置/决策**（如"我们用方案 A"、"这个项目用 pnpm"、"测试不需要 mock"）—— 立即写入，不要等对话结束。

## 写入格式

```markdown
# 跨会话记忆

> 最后更新：<日期时间>

## 当前进行中的事项
- [简要描述正在做的事]（如果有遗留到下次对话的内容）

## 已完成的结论
- <结论1>
- <结论2>

## 持久化决策/偏好
- <用户做的配置决策或偏好>
```

## 注意事项

- 写入时保留旧的记忆内容中仍然有效的部分，删除已过时的部分。
- 不要让记忆文件超过 200 行，优先保留最近和最重要的信息。
- 使用绝对路径 `~/.claude/session_memory.md`。
